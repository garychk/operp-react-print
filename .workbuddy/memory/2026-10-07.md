## locale="auto" 自动跟随宿主语言

- 背景：宿主应用 `<PrintDesigner />` 不传 locale 时固定 zh-CN，不跟随宿主切换。用户选择新增 `locale="auto"` 自动探测方案。
- 关键改动 1（打包架构）：`i18next` / `react-i18next` 从 dependencies 移到 peerDependencies + devDependencies，并在 `vite.config.ts` rollupOptions.external 中外部化 —— 否则组件库自带一份 i18next，与宿主不是同一模块实例，永远读不到宿主语言。ES 产物 381KB → 312KB。
- 关键改动 2（重要教训）：组件库自己的实例 **不能** `.use(initReactI18next)` —— 它会把组件库实例注册为 react-i18next 全局实例（setI18n），宿主未初始化 i18n 时 `getI18n()` 会读到组件库自己（zh-CN），污染 auto 探测。组件内部统一由 `I18nextProvider` 提供实例，已移除该调用。
- 新增 `src/i18n/useResolvedLocale.ts`：`useHostI18nInstance()` 按「I18nextProvider 上下文 → getI18n()（initReactI18next 注册）→ i18next 全局单例（isInitialized）」读取宿主实例并订阅 languageChanged/initialized；`useResolvedLocale(locale)` 对 'auto' 按「宿主实例 → <html lang>（MutationObserver）→ navigator.language（languagechange 事件）→ zh-CN 兜底」解析。
- `src/i18n/index.ts` 新增 `matchLocale`（匹配不到返回 null，供逐源探测）、`detectEnvironmentLocale`、`LocaleOption` 类型；init 同时传 `initAsync:false`（v23+）与 `initImmediate:false`（v22-）兼容宿主不同 i18next 大版本；peer 范围 i18next>=22 / react-i18next>=12。
- `PrintDesigner` 入口拆为三层：`PrintDesigner`（分发 auto/显式）→ `AutoLocalePrintDesigner`（探测）→ `LocaleShell`（落地 changeLanguage + I18nextProvider + ConfigProvider + reseed）。`locale` 类型为 `LocaleOption | (string & {})` 兼容任意字符串简写。
- 新导出：`matchLocale / detectEnvironmentLocale / useResolvedLocale / useHostI18nInstance / LocaleOption`。
- 验证：无头 Chrome + 临时宿主模拟页（`?host=ja-JP`、`?host=zh-CN&switch=en-US` 宿主 2.5s 后切语言、`?nohost=1&lang=ja` 仅 html lang）三场景截图全部跟随正确；显式 `?locale=en-US` 回归正常；tsc app+lib 零错误，vite build 通过。临时验证页已删除。
- lockfile：package-lock.json（npm）与 yarn.lock（yarn 1.22）均已同步。版本号仍为 1.1.4，发布前需自行 bump。

## 主体三栏布局改为百分比

- `PrintDesigner/index.tsx` 的 antd Splitter：左侧 `defaultSize={240}` / 右侧 `defaultSize={260}` 改为左右各 `defaultSize="30%"`，中间不传 size 自适应占 40%。
- 同时把左右 `max={400}`（px）改为 `max="50%"` —— 原 400px 上限与 30% 冲突（1920 宽下 30%=576px 超上限），只约束拖拽不改初始值会造成不一致；`min` 保留 px（左右 80px、中间画布 400px，绝对下限更稳）。
- antd 5.29 Splitter 机制：`isPtg()` 以 `%` 结尾即按百分比解析；初始未测量时 `flexBasis: '30%'` 直接生效无跳动；拖拽按相邻面板 min/max 夹取（px/% 可混用）；collapse 用缓存尺寸恢复。
- 验证：临时测量页实测三种视口（1440/1920/1024）三栏占比均为 30.0% / 40.0% / 30.0%（左 427/571/302px，中 569/760/402px），tsc 零错误、build 通过。临时文件已删。
